# SquirrelNote — Android wrapper + lock-screen quick note

A Capacitor Android app that loads the real SquirrelNote site
(squirrelnote.vercel.app) inside a native shell, plus a standing
notification that lets you jot a quick note down without even unlocking
your phone.

Because the app loads the live site directly (see `server.url` in
`capacitor.config.ts`), shipping a change to the website normally does
**not** require rebuilding this APK — only the native Java parts described
below need a rebuild.

Built and shipped via the `.github/workflows/build-apk.yml` GitHub Actions
workflow, which publishes the APK to the repo's "Latest Android build"
release — see that file for how it's automated, no computer needed.

## What's here

- `android/` — the real Gradle project, generated by the Capacitor CLI.
- `QuickNoteNotification.java` — posts (and re-posts) an always-there
  notification with a "Quick note" reply action. Tapping it lets you type
  directly into the notification itself, right from the lock screen, using
  Android's own reply-to-notification mechanism (the same one messaging
  apps use to let you answer a text without opening it) — a real home-screen
  *widget* can't host live text input at all, which is why this is a
  notification instead.
- `QuickNoteReceiver.java` — handles a submitted quick note. The app isn't
  necessarily running at that moment, so the text gets queued in
  SharedPreferences rather than saved directly, then the notification is
  re-posted so it's ready for the next note immediately.
- `QuickNoteBootReceiver.java` — re-shows the notification after a reboot
  (standing notifications don't survive one on their own).
- `QuickCapturePlugin.java` — a small Capacitor plugin squirrelnote.html
  calls once on startup (`drainQuickCaptures()`) to pull in anything queued
  while the app wasn't open, turning each into a real note. No-op on the
  regular website, where this plugin doesn't exist.
- `MainActivity.java` — registers the plugin, asks for notification
  permission on first launch (required on Android 13+), and makes sure the
  quick-note notification is showing.

## Building tonight

1. Open the `android` folder (not this whole `android-app` folder — the
   inner `android/` one) in Android Studio.
2. Let Gradle sync. First sync will download the Android SDK components
   it needs if Android Studio hasn't already got them.
3. Plug in your phone with USB debugging enabled (Settings → About phone →
   tap Build number 7 times → Developer options → USB debugging), or use
   an emulator.
4. Hit Run. It installs and launches the app, and the quick-note
   notification should appear right away (you may get an Android prompt
   asking to allow notifications — say yes, or the notification won't show).
5. From the lock screen, pull down notifications, tap "Quick note" on the
   SquirrelNote one, type something, and send it. Open the app afterward
   and it should show up as a new note.

## If something doesn't compile

I couldn't build or run this myself directly — no Android SDK or device in
my own sandbox, so building always happens either through the GitHub
Actions workflow or on your own machine, not proven by a build I ran myself.
The most likely rough edges:

- **Package/app ID**: currently `com.pdxwise36.squirrelnote`. Fine to keep,
  or change via Android Studio's rename tooling if you'd rather use
  something else — just make sure it stays consistent across
  `capacitor.config.ts`, `AndroidManifest.xml`, and the Java package
  declarations if you do.
- **Quick-note notification never appears**: usually means the
  POST_NOTIFICATIONS permission prompt got denied, or dismissed without an
  answer. Check Settings → Apps → SquirrelNote → Notifications and make
  sure notifications are allowed, then reopen the app.
- **Typed notes never show up in the app**: means the plugin isn't draining
  the queue. Logcat filtered on `QuickCapturePlugin` or `SharedPreferences`
  will show whether `drain()` is even being called (it runs once, early, on
  every app startup).

## Regenerating this project

If you ever want to start this folder over from scratch instead of hand-
editing it further:

```
cd android-app
npm install
npx cap add android
```

Then reapply the quick-note files (`QuickNoteNotification.java`,
`QuickNoteReceiver.java`, `QuickNoteBootReceiver.java`,
`QuickCapturePlugin.java`, the `MainActivity.java` changes, the
`AndroidManifest.xml` `<receiver>` blocks and permissions) on top of the
fresh scaffold, plus the app icon files under `res/mipmap-*`.
