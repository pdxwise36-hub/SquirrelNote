# SquirrelNote — Android wrapper + Brain Dump widget

A Capacitor Android app that loads the real SquirrelNote site
(squirrelnote.vercel.app) inside a native shell, plus a genuine
home-screen widget for Brain Dump.

Because the app loads the live site directly (see `server.url` in
`capacitor.config.ts`), shipping a change to the website normally does
**not** require rebuilding this APK — only the widget code itself (native
Java, not part of squirrelnote.html) needs a rebuild.

## What's here

- `android/` — the real Gradle project, generated by the Capacitor CLI.
- `BrainDumpWidgetProvider.java` — the home-screen widget. It shows a short
  preview of your brain dump and, when tapped, opens the app straight into
  the Brain Dump editor. Widgets can't host arbitrary web content or live
  text input, so actual typing always happens in the app itself.
- `BrainDumpWidgetPlugin.java` — a small Capacitor plugin. squirrelnote.html
  calls it (via `window.Capacitor?.Plugins?.BrainDumpWidget?.setText(...)`,
  already wired into the existing `saveBrainDumpNow()` — see the main repo)
  every time the brain dump text saves, so the widget preview updates live.
  This is a no-op on the regular website; nothing changes there.
- `MainActivity.java` — registers the plugin and, when launched from the
  widget, fires a `snOpenBrainDump` window event that squirrelnote.html
  listens for to pop the Brain Dump modal open.

## Building tonight

1. Open the `android` folder (not this whole `android-app` folder — the
   inner `android/` one) in Android Studio.
2. Let Gradle sync. First sync will download the Android SDK components
   it needs if Android Studio hasn't already got them.
3. Plug in your phone with USB debugging enabled (Settings → About phone →
   tap Build number 7 times → Developer options → USB debugging), or use
   an emulator.
4. Hit Run. It installs and launches the app.
5. Long-press your home screen → Widgets → find SquirrelNote → drag the
   "Brain dump" widget onto your home screen.

## If something doesn't compile

I couldn't build or run this myself — this sandbox has Gradle but no
Android SDK, and no device/emulator to test on either, so this is
written correctly as far as I can verify by reading it, not proven by an
actual build. The most likely rough edges on a first build:

- **Package/app ID**: currently `com.pdxwise36.squirrelnote`. Fine to keep,
  or change via Android Studio's rename tooling if you'd rather use
  something else — just make sure it stays consistent across
  `capacitor.config.ts`, `AndroidManifest.xml`, and the Java package
  declarations if you do.
- **App icon**: still Capacitor's default placeholder. Not required for
  the widget to work — cosmetic only. Android Studio's Image Asset tool
  (right-click `res` → New → Image Asset) is the easy way to swap it in
  whenever you want.
- **Widget not showing up in the widget picker**: usually means the
  receiver in `AndroidManifest.xml` didn't register — check Logcat for
  `BrainDumpWidgetProvider` and confirm the app actually installed after
  your most recent Run.
- **Widget shows the placeholder text forever**: means `setText` isn't
  reaching the plugin. Open Brain Dump in the app, type something, back
  out — that calls `saveBrainDumpNow()`, which should hit the plugin.
  Logcat filtered on `BrainDumpWidgetPlugin` or `SharedPreferences` will
  show whether the write is happening.

## Regenerating this project

If you ever want to start this folder over from scratch instead of hand-
editing it further:

```
cd android-app
npm install
npx cap add android
```

Then reapply the widget files (`BrainDumpWidgetProvider.java`,
`BrainDumpWidgetPlugin.java`, the `MainActivity.java` changes, the
`AndroidManifest.xml` `<receiver>` block, and the `res/layout` +
`res/xml` + `res/drawable` files) on top of the fresh scaffold.
